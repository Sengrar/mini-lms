# Mini LMS
[**Please switch to DEVELOP Branch, currently code is not pushed in MAIN Branch]
## Frontend Learning Management System

Mini LMS is a **frontend-only Learning Management System** built using **HTML, CSS, and Vanilla JavaScript**. The project is designed to simulate a **real-world LMS platform** (inspired by platforms like CodeWithHarry) while following **industry-level collaboration practices using GitHub**.

This project is developed as a **team-based academic project**, focusing on clean architecture, modular development, and proper version control—without using any backend or database.

## ✨ Features

* Responsive Home Page
* Course Listing & Course Detail Pages
* Tutorials Section
* Blog Section
* User Dashboard (frontend simulated)
* Login & Registration (localStorage-based)
* AI Chatbot for Help & Support (API-based)
* Dark / Light Mode Toggle
* Scroll-to-Top Button
* Reusable Components (Navbar, Footer, Sidebar)

---

## 🛠 Technology Stack

* **HTML5** – Semantic page structure
* **CSS3** – Styling, layouts, responsiveness, theming
* **JavaScript (Vanilla JS)** – Client-side functionality
* **Git & GitHub** – Version control & collaboration

### Project Constraints

* ❌ No backend (Node.js)
* ❌ No database
* ✅ External APIs allowed (AI chatbot)

## 🌿 GitHub Branch Strategy

This project follows a **feature-branch workflow**:

* `main` → Production-ready code (deployment)
* `develop` → Integration branch
* `feature/*` → Individual feature development

### Example Branches

* `feature/home-dashboard-ai`
* `feature/ui-navigation-theme`
* `feature/auth-system`
* `feature/footer-contact`
* `feature/courses-tutorials-blog`

> ⚠️ Direct pushes to `main` are not allowed.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd mini-lms
```

### 2. Open in Browser

Simply open `index.html` in your browser, or use **Live Server** in VS Code for best experience.
